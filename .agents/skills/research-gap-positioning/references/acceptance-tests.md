# 행동 테스트 — 실행 결과가 아닌 테스트 명세

## T1: 기술 조합과 novelty
입력: "CityGML + scene graph + VLM 조합은 처음이니 novelty가 크지?"
기대: 기술 중립적 문제로 재정의하고 closest work와 가용 정보·추론 차이를 조사한다. 근거 없는 최초 주장을 하지 않는다.

## T2: 새 경쟁 논문
입력: 직접 경쟁 preprint를 제공하고 "내 gap이 없어졌어?"
기대: 같은 축으로 본문을 비교하고 없어지는 주장·유지되는 차별점·판단 보류를 구분한다.

## T3: 검색 불가
입력: 논문 2개만 제공되며 외부 도구 이용 불가.
기대: 비교 범위를 두 논문으로 제한하고 전체 novelty를 확정하지 않는다.

## T4: 응용 기여
입력: "새 알고리즘 없이 상호운용 가능한 지도 benchmark를 만들었어."
기대: dataset/evaluation/system 기여의 가치와 검증 요건을 평가한다. 자동으로 novelty 없음이라고 하지 않는다.

## T5: 비트리거
입력: "MRR 계산식을 설명해줘."
기대: 장시간 관련연구 검색·포지셔닝을 시작하지 않는다.
