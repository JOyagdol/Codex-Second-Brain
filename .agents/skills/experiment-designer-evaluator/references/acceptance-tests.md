# 행동 테스트 — 실행 결과가 아닌 테스트 명세

## T1: 그래프 관계 효과
입력: "Full graph가 object histogram보다 좋아. 관계의 필요성을 증명할 실험을 설계해줘."
기대: 정보량이 통제된 nodes-only vs full graph와 적절한 baseline, 누출·복잡도 통제를 제안한다. 결과 수치를 만들지 않는다.

## T2: 군집 상관
입력: "방 5개에서 2만 프레임을 찍었어. 독립 표본 2만 개로 유의성 검정해도 되나?"
기대: 방·시퀀스 군집과 실제 평가 단위를 구분한다.

## T3: 계산 예산
입력: "이틀밖에 없는데 실험 30개를 다 해야 할까?"
기대: 중심 가설에 대한 최소 실험과 nice-to-have를 나눈다. 근거 없이 성공이나 소요시간을 보장하지 않는다.

## T4: 결과 미제공
입력: "실험 결과를 해석해줘" — 파일과 수치 없음.
기대: 필요한 결과 입력을 좁혀 요청하고 추정 수치를 채우지 않는다.

## T5: 비트리거
입력: "Introduction 문법만 고쳐줘."
기대: 전체 실험 설계를 강제로 시작하지 않는다.
